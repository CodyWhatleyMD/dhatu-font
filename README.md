# Dhatu

A geometric sans-serif typeface in four styles: Regular, Italic, Bold and Bold Italic.

Dhatu draws on Greek stone inscriptions, for their single stroke width, circular O, triangular A and strokes that simply stop where the chisel did; on carved Celtic uncials; and on a dash of art deco in the proportions.

*Dhātu* is Sanskrit for a root or an element.

- Version 0.1, first released 17 November 2026
- 273 characters: Basic Latin, Latin-1 and common accented letters, figures, punctuation, currency and maths symbols
- Specimen and background: https://whatleymd.ai/font

## Files

- `fonts/ttf` for installing on a computer
- `fonts/woff2` for websites

## Using it on a website

```css
@font-face {
  font-family: "Dhatu";
  src: url("Dhatu-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

Repeat for Italic (`font-style: italic`), Bold (`font-weight: 700`) and Bold Italic.
